# 404

## When it applies

Every site has one. `project-init` installs a neutral 404 on the foundation's tokens, because Sage's default fails the launch (SEO-10). A site restyles it from the comp's 404 board, or keeps it when the file has none. Phase 5 of `figma-design-system` covers it. A 404 is a template, not a block, so it has no canvas.

## Built from

- `resources/views/404.blade.php` and `partials/not-found.blade.php`
- `App\View\Composers\NotFound`, which gives every text a default and reads the optional Site Settings › 404 tab (`site-settings-wizard`)
- The layout it extends
- `<x-button-link>`
- `heading-1`, `text-body`, `btn btn-primary`

## Rules that matter most

- I18N-1: every string goes through `__()`.
- VIEW-3: a template owns the page's `<h1>`.
- VIEW-6: colors and sizes come from tokens and type classes.
- A11Y-5: large "404" numerals are decorative and `aria-hidden`.
- ESC-1, ESC-2: URLs and text print safely.

## Adapt per design

- The numerals, the alignment and the space around the copy.
- The wording, kept short and kind, in the composer's defaults.
- An illustration or a search field, if the comp shows one.

## Do not change

- The page extending the layout.
- A way back to the home page.
- The heading as the page's `<h1>`.
- A `min-height`, never a fixed `height`, if it fills the screen.
